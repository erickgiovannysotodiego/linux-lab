# Comandos Usados - Semana 05

* `uname -a`: Información completa del sistema y kernel.
* `uptime -p`: Tiempo de actividad formateado (pretty).
* `nproc`: Número de núcleos de CPU.
* `free -h`: Estado de memoria RAM en formato legible.
* `df -h`: Reporte de espacio en disco en formato legible.
* `ps aux --sort=-%cpu`: Listado de procesos ordenado por uso de CPU.
* `hostname -i`: Dirección IP del host actual.
* `printf`: Formateo de salida para tablas y reportes.
