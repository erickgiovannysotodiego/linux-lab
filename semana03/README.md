# Semana 03: Procesamiento de Texto y Pipes

## Descripción
Analizador automatizado de logs diseñado para auditar el comportamiento de un servidor web mediante flujos de datos (`|`) y expresiones avanzadas.

## Instrucciones de Uso
1. Generar los datos de prueba: `./generate-sample-log.sh`
2. Procesar y ver reporte: `./log-analyzer.sh`
